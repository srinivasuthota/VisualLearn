How does Queue work?

Queue follows the FIFO principle: First In, First Out. The first element added is the first element removed.

Enqueue O(1)
Dequeue O(n)*
Peek O(1)
*This visualizer uses a JavaScript array and removes the first item with slice(), which copies the remaining items. A linked-list or circular-buffer queue can perform dequeue in O(1).
