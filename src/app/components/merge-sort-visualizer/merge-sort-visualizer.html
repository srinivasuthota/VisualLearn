ALGORITHM ANALYSIS

Why O(n log n)?

Understand how splitting and merging determine the time complexity.

SPLITTING LEVELS log₂(n)

Each split divides an array into smaller halves until single elements remain.

WORK PER LEVEL O(n)

At each merge level, all n elements are processed.

TOTAL TIME O(n log n)

Number of levels multiplied by the work at each level.

EXTRA SPACE O(n)

Temporary arrays are used while merging elements.
